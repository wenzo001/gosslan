# 真机验收清单（5.18.78）

> 这份清单只写**怎么点、看到什么算过**，不写代码名词。
> 一共 5 项：A③ 屏幕边缘安全区、C⑦ 长按消息、C⑨ Windows 图标、C⑩ Windows 标题栏、C⑪ 背景动效读数。
> 第 1 项在安卓上做，第 3/4/5 项在 Windows 上做，第 2 项在安卓上做。
> 每项都写了「出问题要截什么图」——截图比描述有用，拍到了就能定位。

## 开始之前：确认你装的是 5.18.78

1. 打开应用 → 左下角/标题栏进「设置」→「关于」。
2. 在「关于」里找到版本号，应该是 **5.18.78**。
3. 不是这个版本 → 先升级，否则下面几项的结论对不上号。

---

## 1（A③）安卓：提示条不要压到状态栏，底部导航不要被系统手势条盖住

**设备**：任意安卓手机（真机最好，模拟器也能看个大概）。

**怎么点**：

1. 把手机系统导航方式切到「手势导航」，打开应用。
2. 看底部那条应用自己的导航栏（会话 / 联系人 / 传输队列 / 设置 那一排）：
   它的底边和屏幕最底边之间，应该有明显的留白（约一个大拇指指甲的高度）。
3. 随便点一下「设置 → 关于 → 设备指纹」把它复制，屏幕下方会冒出一条「已复制」的小提示，
   看这条提示有没有压到屏幕最下面。
4. 把系统导航切到「三键导航」，重复第 2、3 步。
5. 如果你手边有上次崩溃过的那台机器：崩溃后出现的提示条（右下或顶部，带「知道了」），
   看它是否压在顶部状态栏（时间/电量那一排）或底部手势条上。

**预期看到**：应用的导航栏、提示条都在「安全区」以内 —— 离屏幕四边和四角都留出距离，
文字和按钮完整可见，没有被状态栏、手势条、圆角切掉。

**和现在的差别**：以前这些提示条是直接贴着屏幕边的，在安卓上会被状态栏/手势条压住一截；
现在是「离边留一段」。

**不通过时截什么图**：
- 一张能同时看到「提示条 + 顶部状态栏」的整屏截图；
- 一张能同时看到「底部导航栏 + 屏幕底边」的整屏截图；
- 如果是崩溃提示，把那条提示和状态栏一起拍进去。

## 2（C⑦）安卓：长按一条文字消息，先出面版，再选文字

**设备**：安卓手机（这一条必须在安卓上看，桌面端的右键菜单是另一套）。

**怎么点**：

1. 打开一个聊天，找到一条**文字**消息（不要图片）。
2. 长按这条文字约 1 秒。
3. 应该弹出消息面版（复制 / 转发 / 收藏 / 回复 / **选择文字** 等按钮）。
4. 点面版里的「**选择文字**」。
5. 用手指按住文字拖动，选中一小段。
6. 松开手指，看有没有出现系统的「复制 / 全选」小工具条；点「复制」。
7. 粘贴到输入框里，看粘出来的是不是你选中的那段。

**预期看到**：第 3 步先出面版（这是关键）；第 4 步之后文字可以被选中，
第 6 步出现系统复制工具条，第 7 步粘贴出正确内容。

**和现在的差别**：在 5.18.77 上，长按正文会被系统直接抢走去做选字，
面版根本不弹（图片是正常的）。5.18.78 改成「面版先出来，点了『选择文字』才进入选字」。

**不通过时截什么图**：
- 长按之后**面版没弹出**：拍长按后的整屏（能看到那条消息和周围）；
- 面版弹出但「选择文字」点了没反应：拍点了之后的整屏；
- 能选中但复制不出来：拍选中状态（带系统工具条）和粘贴后的输入框。

## 3（C⑨）Windows：升级之后图标要变成新图标，并且是圆角

**设备**：Windows 10 或 Windows 11 电脑。

**怎么点**：

1. 先看一眼**升级前**的桌面快捷方式图标和任务栏图标（如果还找得到旧版），拍张照。
2. 用应用内的升级（或直接覆盖安装）升级到 5.18.78。
3. 升级完成后，看**桌面快捷方式**的图标。
4. 看**任务栏**上的应用图标（没固定在任务栏的话，从开始菜单打开一次再看）。
5. 如果图标还是旧的：按 `Win + R`，输入 `ie4uinit.exe -show` 回车（这是让 Windows 重读图标缓存的系统命令），
   再看一次。

**预期看到**：桌面和任务栏都是**新的圆角图标**（和 macOS 上看到的是同一张图），
不再是旧图标、也不是直角方图。

**和现在的差别**：以前覆盖安装后 Windows 会继续用缓存里的旧图标；
Windows 11 也不会自动给应用图标加圆角。这次两件都改了。

**不通过时截什么图**：
- 桌面快捷方式的局部放大截图（图标 + 文件名）；
- 任务栏图标的局部放大截图；
- 跑了 `ie4uinit.exe -show` 之后仍然旧图的话，再拍一张，并在反馈里说明「跑过这条命令之后还是旧的」。

## 4（C⑩）Windows：标题栏的头像和按钮应该在**左边**

**设备**：Windows 10 / 11 电脑。

**怎么点**：

1. 打开应用，看最上面那条标题栏。
2. 确认窗口右上角是 Windows 自己的三个按钮（最小化 / 最大化 / 关闭）。
3. 看标题栏**左上角**：应该有一组小图标，从左到右依次是
   **头像 → 设置 → 搜索 → 局域网状态**。
4. 看这组图标离窗口上边、左边的距离是不是**一样**（大约 6 像素，肉眼是「贴角但留一点缝」）。

**预期看到**：这组图标在左边，顺序是 头像 → 设置 → 搜索 → 局域网；
中间的标题文字仍然是正中间，不偏。

**和现在的差别**：以前这组图标在**右边**（跟 macOS 一致），会跟 Windows 的三个按钮挤在一起；
现在按「系统按钮在哪边，头像簇就放另一边」镜像到左侧。

**不通过时截什么图**：
- 左上角 4 倍放大截图（要能看清图标和窗口圆角）
- 右上角 4 倍放大截图（三个系统按钮）
- 整条标题栏的截图（用来看标题是否真的居中）

## 5（C⑪）Windows：复制一段「背景动效读数」发回来（macOS 也照做一次做对照）

这一条是**取数据**，不是判断对错。目的是拿到两台机器上真实的环境读数，才能解释
「为什么 Windows 和 macOS 背景动效看起来不一样」。

**设备**：出问题的那台 Windows 电脑；再用你自己的 macOS 做一次对照。

**怎么点**（两台机器步骤完全一样）：

1. 打开应用 → 左侧/标题栏进「**设置**」。
2. 左边分组里点「**关于**」。
3. 找到「**设备指纹**」下面那串很长的字符，**连续快速点它 7 下**（大约 2 秒内点完）。
4. 会弹出一个窗口，标题是「**网络诊断（开发者）**」。
5. 把窗口内容**拉到最下面**，会看到一块「**背景动效读数**」，
   右上角有一个「**复制诊断信息**」按钮。
6. 点「复制诊断信息」——按钮会短暂变成「**已复制**」。
7. 打开聊天窗口或记事本，粘贴，把这一整段发回来。

**预期看到**：面板最底部是「背景动效读数」，标题右边有「复制诊断信息」，
下面是一列「名字: 值」的对照表，共 13 行，大致长这样（**下面是示例，数值以你的机器为准**）：

```text
platform: macOS
prefers-reduced-motion: reduce: off
prefers-reduced-transparency: reduce: off
prefers-contrast: more: off
forced-colors: active: off
pointer: coarse: off
html[data-ambient]: full
backdrop-filter: supported
--ambient-alpha: 0.3
--ambient-veil: 0.16
--ambient-scale: 1.3
devicePixelRatio: 2
viewport: 1180×760
```

**和现在的差别**：这一段读数以前没有，是这个版本新加的；有了它，
「Windows 上看起来更淡 / 更糊 / 不动」这类问题才能对着数字说清楚。

**这个入口在正式版里也有吗**：有。它不是开发版专属，安装包装出来的正式版一样能点到，
只是藏得比较深（要连点 7 下设备指纹）。

**注意**：面板里其他部分（局域网、蓝牙那一堆）不用管，只要最下面这一块。

**不通过时截什么图**：
- 连点 7 下之后**没有弹窗**：拍「关于」页面里设备指纹那一行；
- 弹窗出来了但找不到这一段：拍面板**最底部**那一屏；
- 按钮点了不变「已复制」：拍按钮当时的名字。
