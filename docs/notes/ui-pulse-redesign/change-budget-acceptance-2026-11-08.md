1. **信号是真的。** 被点名的提交都改 `src/`（或与之同批的前端外壳），而 `presentation` 的领域映射
   覆盖整个前端；窗口里确实连续多笔同域修补形状提交。没有改领域映射、没有缩小窗口来消红。

   chrome / 崩溃取证 / 启动错误 / 选中态），按用户「分笔提交、一处一报（截图 + 读数 + 提交号）」的
   明确要求落地。形态统计无法区分「同领域独立任务」与「同领域反复打补丁」，本批属于该统计的
   假阳性 —— 与 2026-11-07 两次接受的判定口径一致。
3. **规则原文只给了两条正路。** [check-change-budget.mjs](../../../scripts/check-change-budget.mjs)
