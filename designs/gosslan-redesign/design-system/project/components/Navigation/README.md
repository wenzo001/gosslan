# Navigation

Two navigation surfaces, one visual language.

- Desktop rail is 64px: avatar at the top, four destinations (Chats, Contacts, Favorites, Links), theme and more at the bottom. Icons 22px at 1.75px stroke; active state is a 38px rounded-10 pill in `accent-soft`.
- Unread counts use one 16px capsule on the icon's top-right, never a dot plus a count.
- Mobile tab bar is 56px + safe area: Chats, Contacts, Favorites, Me. Active state is a 46×26 pill behind a 21px icon, with an 11px label below.
- Detail pages hide the tab bar; back is a 44px target at the top-left.
- The title bar is 40px on desktop: window controls at the platform's side, a quiet centred app name, LAN status and global search at the right. Nothing floats above it.
