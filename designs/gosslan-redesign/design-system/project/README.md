# Gosslan Still — 设计系统

> 冷静、贴近原生、以信息效率为先的局域网即时通讯设计语言。
> 这一版不是把旧界面换皮，而是把「消息」重新放回界面的中心。

---

## 1. 设计立场

Gosslan 的使用场景是**熟人局域网**：同事、家人、宿舍、工作室。它不像公网 IM 那样需要强运营、强娱乐、强存在感。它应该像一张干净的桌面：打开就能说话，说完就能放下。

**Still** 的三条主张：

1. **消息优先于容器。** 界面骨架退到低对比的中性灰里，白底只留给会话与内容。没有漂浮卡片、没有层层玻璃、没有装饰性渐变。
2. **密度是礼貌。** 桌面端一屏看到更多会话、更多历史；气泡紧凑，但行高和点击区不缩水。移动端把 44px 触控目标当硬约束。
3. **状态要能被看见。** 发送中、失败、离线、传输进度、未读、好友申请，都必须有一致且不打扰的表达，而不是靠用户猜。

### 反面清单（明确不做）

- 不做后台管理系统的表格化、卡片化、蓝灰渐变。
- 不做「毛玻璃叠毛玻璃」；浮层只允许一层半透明 + 实色内容。
- 不用 emoji 当 UI 图标；不用手绘风格不统一的 SVG。
- 不用大面积品牌色铺底；强调色只出现在动作、选中、自己发送的消息上。
- 不为了留白把消息列表拉成稀疏的落地页。

## 2. 视觉基调

**关键词**：暖中性、细分隔线、单强调色、轻阴影、稳定节奏。

- **底色**：带一点暖灰的纸面感（`surface-canvas`），不是冷蓝灰。浅色与深色都保持同一套语义层级。
- **层级**：靠**表面明度差 + 1px 发丝线**建立，不靠大阴影。只有菜单、弹窗、命令面板使用阴影。
- **强调色**：单一钴蓝（`accent`）。自己发送的气泡、主按钮、选中态、焦点环共用它。
- **语义色**：成功、警告、危险各自分「填充档」和「文字档」，避免白字压在浅色上。
- **圆角**：控件 8px，卡片 10–12px，气泡 18px，头像与徽标全圆。圆角随尺寸增大，但不出现 24px 的大圆角卡片。
- **图标**：统一 1.75px 描边、圆角端点、20px 为主。线性图标贯穿全产品，状态点用实心圆，不用两套图标混搭。

**对比度规则**

- 正文与小字在各自表面 ≥ 4.5:1；大标题 ≥ 3:1。
- 强调色作为填充时，前景一律 `text-on-accent`；作为文字时改用 `accent-ink`，不要直接拿 `accent` 写小字。
- 状态色不要只靠色相区分：在线/离线同时有实心点与文字；文件状态同时有图标与文字。
- 深色主题不是浅色反相：深色里气泡对比较低，靠 `bubble-in-border` 与明度差保证边界。

## 4. 字体

**西文**：Inter（400 / 500 / 600），系统回退 `-apple-system, Segoe UI`。
**中文**：PingFang SC（macOS）、Microsoft YaHei（Windows）、系统默认（Android/Linux）。
**等宽**：JetBrains Mono，用于代码块、链接地址、日志。

| 样式 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display-lg` | 28/34 | 600 | 空状态主标题、欢迎页 |
| `display` | 24/30 | 600 | 页面标题 |
| `title-lg` | 20/26 | 600 | 设置页大标题 |
| `title` | 17/24 | 600 | 会话标题、弹窗标题 |
| `headline` | 15/20 | 600 | 列表分组标题、按钮 |
| `body` | 14/20 | 400 | 消息正文、设置项 |
| `body-strong` | 14/20 | 500 | 会话名、未读会话 |
| `body-sm` | 13/18 | 400 | 摘要、输入框、次级说明 |
| `body-sm-strong` | 13/18 | 500 | 行内强调、标签 |
| `caption` | 12/16 | 400 | 时间、辅助说明 |
| `micro` | 11/14 | 500 | 群聊发送者名、徽标、最小元数据 |
| `code` | 12.5/18 | 400 | 代码与日志 |

**排版规则**

- 中文正文行高不低于 1.4×；消息正文 14/20（桌面）、15/21（移动）。
- 不用 300 细字重；深色主题尤其避免细字。标题与正文靠字重、颜色分层，不靠字号暴涨。
- 数字与时间使用 tabular nums（`font-variant-numeric: tabular-nums`），列表时间列不跳动。
- 单行摘要必须省略号截断；会话名最多两行，摘要永远一行。

## 5. 间距与节奏

8px 基准，允许 2/6/10 的微调。

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `space-2` | 2px | 同一人连续气泡之间 |
| `space-4` | 4px | 图标与文字 |
| `space-6` | 6px | 紧凑徽标内边距 |
| `space-8` | 8px | 行内控件 |
| `space-10` | 10px | 气泡上下内边距 |
| `space-12` | 12px | 气泡左右内边距、消息组间距 |
| `space-16` | 16px | 列表行左右缩进 |
| `space-20` | 20px | 页面 gutter |
| `space-24` | 24px | 区块间距 |
| `space-32` | 32px | 大区块 |
| `space-40` | 40px | 空状态顶部留白 |

**消息节奏（关键）**

- 同一发送者连续消息：气泡间距 **2px**，只在第一颗显示头像与名字。
- 不同发送者之间：**12px**；跨时间分组再加 **8px**。
- 日期分隔：上下各 16px，居中 11px 文字，不加背景胶囊。
- 气泡内边距：`8px 12px`；单行气泡高度约 36px；图片气泡无内边距。
- 气泡最大宽度：桌面 `min(560px, 68%)`；移动 `78%`。
- 自己消息右对齐、对方左对齐；群聊对方消息保留 24px 头像列，单聊不要头像列，把空间还给文字（iMessage 式）。

## 6. 圆角与层级

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-xs` | 4px | 文件类型角标 |
| `radius-sm` | 6px | 行内代码 |
| `radius-md` | 8px | 按钮、输入框、菜单行 |
| `radius-lg` | 10px | 卡片、图片缩略图 |
| `radius-xl` | 12px | 对话框、设置面板 |
| `radius-bubble` | 18px | 消息气泡 |
| `radius-full` | 999px | 头像、状态点、胶囊 |

- 气泡连接处：同一人连续消息，内侧上/下角改为 6px，形成自然堆叠；不同人恢复 18px。
- 阴影只用于「离开页面平面」的东西：菜单 `shadow-md`、对话框 `shadow-dialog`、吸顶栏 `shadow-xs`。
- 不做全局玻璃。允许标题栏与移动底栏使用 92% 不透明表面 + 背景模糊，但内容区永远实色。

## 7. 图标

**统一规格**

- 24×24 viewBox，线性描边 **1.75px**，`stroke-linecap="round"`，`stroke-linejoin="round"`。
- 常用尺寸 16 / 20 / 24；导航 22；空状态 40–48。
- 图标颜色继承文字色；激活态用 `accent-ink`，不要给图标单独上渐变。
- 图标按钮必须有 `aria-label`；纯装饰图标 `aria-hidden="true"`。
- 不用 emoji 代替图标；群头像可以用文字首字或预设图形，但界面控件不用 emoji。

**核心图标集（Lucide 语义）**

`message-circle` 聊天 · `users` 通讯录 · `star` 收藏 · `link` 链接 · `settings` 设置 · `search` 搜索 · `plus` 新建 · `more-horizontal` 更多 · `chevron-left/right` 层级 · `arrow-up` 发送 · `paperclip` 附件 · `image` 图片 · `smile` 表情 · `check` 已发送 · `check-check` 已读 · `clock` 发送中 · `alert-circle` 失败 · `download` / `upload` 传输 · `file` 文件 · `x` 关闭 · `sun` / `moon` / `monitor` 外观 · `wifi` / `wifi-off` 连接 · `bell` 通知 · `lock` / `shield` 安全 · `database` / `hard-drive` 存储 · `refresh` 重试 · `trash` 删除 · `pin` 置顶 · `reply` 回复 · `forward` 转发 · `copy` 复制 · `edit` 编辑 · `user-plus` 加好友 · `qr-code` 扫码 · `folder` 文件夹 · `list` 任务 · `filter` 筛选 · `eye` 预览.

## 8. 布局

### 8.1 桌面（默认窗口 1000×680，可放大到 1440+）

```
┌──────────────────────────────────────────────────────────┐
│ 标题栏 40px：拖动区 · 窗口控制 · 全局搜索 ⌘K             │
├──────┬──────────────────┬────────────────────────────────┤
│ rail │ 列表 320px       │ 内容区（聊天 / 详情）           │
│ 64px │ 搜索 + 列表      │ 52px 头部 + 消息 + 输入区       │
│      │                  │                                │
└──────┴──────────────────┴────────────────────────────────┘
```

- rail 固定 64px；图标 22px，激活项用 36px 圆角胶囊 + `accent-soft`。
- 列表宽 280–400px，可拖拽；默认 320px。头部 52px 放标题与「新建」。
- 内容区最小宽度 420px；低于 900px 时列表自动收窄到 280px；低于 768px 进入移动布局（单栏 + 返回）。
- 聊天消息列最大 760px 居中；右侧群信息面板 300px 可折叠，开启时消息列仍居中。
- 设置/资料/日志作为**独立窗口**或主区整页覆盖：桌面用双栏（左侧 220px 分区导航，右侧内容最大 720px）。
- 不做右侧固定「详情栏」挤压聊天：群成员/群文件用抽屉或整页，需要时再开。

### 8.2 移动（360–430px）

- 顶部 56px：返回/标题/操作；一级页左上角是头像或标题，不放汉堡菜单。
- 底部 56px + 安全区：聊天 / 通讯录 / 收藏 / 我的，四项。
- 列表行 68px：头像 44px，名字 15/20，摘要 13/18，时间 11px，未读点 8px。
- 聊天页：返回 + 头像/名字 + 在线状态 + 更多；输入区 52px 起，附件与表情在输入框左侧，发送键在右侧。
- 二级页隐藏底栏；从右侧滑入，返回手势/按钮回退。
- 所有可点区域 ≥ 44×44；列表行整行可点，不用小箭头当唯一入口。

### 8.3 响应式断点

| 宽度 | 模式 |
| --- | --- |
| ≥ 1100px | 三栏，列表 320px，可选信息栏 |
| 768–1099px | 三栏，列表 280–300px，无信息栏 |
| < 768px | 单栏 + 底栏，详情页覆盖 |
| < 380px | 字号降一档，列表行 64px，隐藏次要元数据 |

## 9. 核心组件

### 9.1 会话行 `ConversationRow`

- 高度 68px，左右 16px；头像 44px 圆形（群聊可用圆角方形 12px 作区分）。
- 第一行：名称（15/20，500）+ 时间（11px，`text-tertiary`，tabular）。
- 第二行：摘要（13/18，`text-secondary`，单行省略）；自己发的消息前缀「你：」。
- 右侧：未读胶囊（最小 18px，`accent` 填充白字）或免打扰小铃铛；不要同时堆三个徽标。
- 选中：整行 `accent-soft`，左侧不加色条；悬停只提亮 4%。
- 置顶会话在列表顶部，不单独分组，用 11px「置顶」标签区分。

### 9.2 消息气泡 `MessageBubble`

- 自己：`bubble-out` 填充、白字、右下角 6px；对方：`bubble-in` 填充、`bubble-in-text`、左下角 6px。
- 单行气泡高度 36px；多行行高 20px；图片/文件气泡独立圆角 12px。
- 时间不挂在每个气泡上；同一分钟组只在组尾显示 11px 时间，悬停/长按显示完整时间。
- 发送状态只出现在**自己最后一条**消息下方 11px：`clock` 发送中、`check` 已发送、`check-check` 已读、`alert-circle` 失败 + 「重试」文字按钮。
- 引用：气泡内顶部 2px 左侧细线 + 11px 引用摘要，不另起一个大胶囊。
- 表情回应：贴在气泡下沿，18px 高胶囊，最多显示 3 个 + `+N`。
- 群聊：头像 24px 在左，发送者名 11px `text-tertiary` 仅在每组第一条出现；自己消息不显示头像与名字。

### 9.3 输入区 `Composer`

- 容器 52–64px，上边 1px `divider`；内部不是大圆角卡片，而是**无边框的整行输入**，聚焦时只在容器外圈出现 2px `focus-ring`。
- 左侧：附件、图片、表情；右侧：发送按钮（36px 圆，`accent`，空内容时 `surface-field` + `text-tertiary`）。
- 支持多行，最高 160px 后内部滚动；Enter 发送、Shift+Enter 换行（桌面），移动端发送键独立。
- 拖拽文件时整个聊天区出现 2px 虚线 `accent` 内框 + 居中提示，不弹新窗口。

### 9.4 头部 `ChatHeader`

- 52px；左侧返回（移动）/头像 32px；名称 15/20 600；第二行 11px 在线状态或「3 人在线 · 局域网」。
- 右侧：搜索、群信息/成员、更多；图标按钮 30px，间距 4px。
- 断线时第二行变 `warning-ink`「正在重连…」，不遮挡内容；重连成功 2 秒后恢复。

### 9.5 列表页头部

- 52px：标题 17/24 600 + 右侧「新建」图标；下一行 40px 搜索框（`surface-field`，8px 圆角，放大镜 + 占位文字）。
- 搜索框常驻，不做点开才出现的全屏搜索；⌘K 聚焦。
- 分组标题 12px 500，`text-tertiary`，上下 8px；不加大底色。

### 9.6 设置

- 分组：标题 12px 500 `text-tertiary`；组内行 52px，白底，圆角 12px，行间 1px `divider` 缩进 16px。
- 行：左侧标签 14/20，可选 12px 说明；右侧控件（开关、下拉、值 + chevron）。
- 危险操作单独分组，文字 `danger-ink`，不做红色整行填充。
- 桌面设置双栏；移动设置单列，分组卡片间距 20px。

### 9.7 菜单、弹窗、Toast

- 上下文菜单：`surface-raised`、10px 圆角、`shadow-md`、6px 内边距；行高 32px，图标 16px；危险项 `danger-ink`。
- 对话框：最大 420px，12px 圆角，`shadow-dialog`；标题 17/24，正文 13/18 `text-secondary`；按钮右对齐，主按钮在右。
- Toast：底部居中（桌面右下），`surface-raised`，10px 圆角，`shadow-md`，最长 4 秒；成功/失败用图标 + 文字，不用整块彩色。
- 确认删除：必须写清对象与后果；危险按钮文案用动词（「删除会话」「退出群组」），不用「确定」。

## 10. 交互状态

每个可交互组件都必须覆盖：

| 状态 | 表达 |
| --- | --- |
| Default | 按 token 绘制 |
| Hover | 表面提亮/加深 4–6%，不位移；桌面光标 pointer |
| Pressed | 再深一档，缩放 0.98（仅按钮），120ms |
| Focus | 2px `focus-ring` 外环 + 2px offset；键盘可见，鼠标点击不显示 |
| Disabled | `opacity-disabled`，禁用光标，保留布局 |
| Loading | 内容位置不变；按钮内 16px 旋转指示器；列表用 3 行骨架（不发光的灰块） |
| Success | 图标 + 文案，2 秒后淡出；不弹大弹窗 |
| Error | 就地显示在出错对象旁；提供「重试」；不吞掉已输入内容 |
| Offline | 顶部 32px 细横幅 + 头部状态；输入框仍可输入，发送按钮进入排队态 |

**空状态**

- 结构：40px 线性图标（`text-tertiary`）+ 17/24 标题 + 13/18 说明（最多两行）+ 一个主行动。
- 空状态不写营销文案，不放大插画；说明必须告诉用户「为什么空」和「下一步做什么」。

## 11. 动效

- 时长：按下 120ms；展开/收起 180ms；页面转场 240ms；对话框 240ms。
- 缓动：标准 `cubic-bezier(.2,0,0,1)`；进场 `cubic-bezier(.16,1,.3,1)`；退场 `cubic-bezier(.4,0,1,1)`。
- 只动 `opacity` 与 `transform`；不动宽度/高度（列表展开除外，且不超过 180ms）。
- 元素出现只播一次；状态切换（选中、发送成功、未读清除）不重播缩放入场。
- 新消息进入：底部 8px 上移 + 淡入 180ms；不推动正在阅读的历史。
- 滚动时不做视差、不做背景模糊跟随。
- `prefers-reduced-motion`：只保留 120ms 淡入淡出，取消位移与缩放。

---

## 12. 内容与语气

- 中文优先、简洁、动词开头；按钮 2–4 字（「发送」「添加」「重试」「退出群组」）。
- 不用「亲」「哦」等运营语气；系统消息用陈述句。
- 时间：今天显示 `14:32`，昨天 `昨天`，更早 `10月24日`，跨年 `2025/10/24`。
- 文件大小：`1.2 MB`、`860 KB`；传输速度 `3.4 MB/s`；剩余时间 `约 12 秒`。
- 错误：说清「什么失败 + 为什么（若已知）+ 怎么办」，不显示裸错误码；日志页才展示技术细节。

---

## 13. 可访问性

- 所有图标按钮有 `aria-label`；所有输入有可见 `<label>` 或 `aria-label`。
- 键盘：Tab 顺序按视觉顺序；Esc 关闭浮层；⌘K 搜索；Enter 发送；方向键在菜单内移动。
- 焦点环永不被 `outline: none` 抹掉；自定义控件保留原生语义。
- 颜色不是唯一信息通道；未读、在线、失败都同时有形状/文字。
- 触控目标 ≥ 44px；桌面图标按钮 ≥ 30px 且外扩热区到 36px。
- 文本缩放 200% 时布局不重叠；列表摘要可换行或截断，不裁掉按钮。

## 14. 与旧界面的关键差异

| 维度 | 旧界面 | Still |
| --- | --- | --- |
| 表面 | 蓝灰玻璃、多层半透明、色雾 | 暖中性实色 + 单层浮层 |
| 导航 | 64px rail + 大图标 + 底部版本号/主题按钮 | rail 保留 64px，但图标更小、激活胶囊更克制；版本移入「我的/关于」 |
| 列表 | 行高偏大、信息层级弱、空状态文案过长 | 68px 行、名称/摘要/时间三级清晰、空状态只留一个行动 |
| 单聊 | 气泡大、留白多、头像列占空间 | iMessage 式无头像列、36px 单行气泡、2px 组内间距 |
| 群聊 | 自己与他人区分弱 | 对方 24px 头像 + 11px 名字；自己无头像、蓝气泡 |
| 设置 | 单列长页、控件样式多 | 双栏分区、52px 行、统一开关/下拉/分段 |
| 状态 | 提示散落、toast 计数问题 | 统一状态语言：就地错误 + 顶部离线条 + 组尾回执 |
| 图标 | 内联 SVG 风格不一 | 统一 1.75px Lucide 语义图标 |
| 深色 | 偏蓝黑、对比不稳 | 中性炭黑、独立校验的语义色 |

## 15. 使用方式

- 所有页面从 `tokens.json` 取值；画板内以十六进制落地，便于设计工具直接读取。
- 新增组件先回答：它属于哪个表面层级？它的 hover/pressed/focus/disabled/loading/error 是什么？它占多少高度？
- 任何「为了好看」而增加的阴影、渐变、圆角、彩色底，默认拒绝；先证明它承载了信息。
