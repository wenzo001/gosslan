# 边界情况规范 — 长文本、溢出与密集信息

> 设计画板：`DesktopEdgeCases.dc.html`、`MobileEdgeCases.dc.html`（画布 `05 Edge cases`）。
> 目标：任何合法内容都不能把布局撑破；信息再密，也要能一眼分清主次。

## 1. 四条总规则

1. **先给固定槽位，再让中间伸缩。** 时间、未读数、右侧按钮、头像固定宽；中间文本 `min-width:0` + 省略。
2. **文本只有三种收束方式。** 单行省略、最多两行、任意断行。不要出现第四种“随它撑”。
3. **断行只给该断的东西。** 中文正常换行；URL、长英文单词、IPv6、安全码才用 `overflow-wrap:anywhere` / `word-break:break-all`。
4. **字号有下限。** 正文 ≥ 13px，辅助 ≥ 11px，密集卡片最低 10.5px；不靠缩小字号塞信息。

## 2. 各表面的处理方式

| 表面 | 处理 | 上限 | 额外要求 |
| --- | --- | --- | --- |
| 会话名 / 联系人名 | 单行省略 | 1 行 | 桌面 hover 显示 `title`；移动长按可查看资料 |
| 会话预览 | 单行省略 | 1 行 | 文件消息显示 `[文件] 文件名`，文件名也省略 |
| 时间 / 未读 | 固定槽位 | 1 行 | 未读 > 99 显示 `99+`；不把时间挤走 |
| 聊天标题 | 单行省略 | 1 行 | 返回、更多保持 44px 热区 |
| 聊天副标题 | 单行省略 | 1 行 | 成员数、在线数优先保留 |
| 消息气泡 | 中文换行；URL/长单词任意断行 | 最大 68% 桌面 / 78% 移动 | 不产生横向滚动；引用最多 1 行 |
| 文件卡 | 文件名单行省略 | 1 行 | 大小/状态单行；图标固定 32×38 |
| 搜索摘要 | 两行截断 | 2 行 | 高亮词不撑破行；结果标题单行 |
| 任务路径 / 错误原因 | 两行截断 | 2 行 | 进度条高度固定，不随换行跳动 |
| 设备名 | 自然换行 | 2 行 | 超出 2 行省略 |
| IPv6 / 安全码 / 邀请码 | 等宽字体 + 任意断行 | 不限 | 禁止横向溢出；可长按复制 |
| Toast | 最多两行 | 2 行 | 桌面最宽 420px；移动左右各 12px |
| 对话框标题 | 最多两行 | 2 行 | 对象名完整可读；按钮文字不换行 |
| 输入草稿 | 1 行起，最多 5 行后内部滚动 | 5 行 | 发送键不动；IME 组合中不误发 |
| 空态 / 错误说明 | 自然换行 | 3 行 | 主 CTA 不被长文案挤走 |

## 2.1 状态显示：一个状态只出现一次

- **头像已有在线/离线点**时，旁边不再出现第二个绿点或“在线/离线”文字；meta 只写设备、网络等上下文。
- **联系人分组**已经用“在线 · 3 位 / 离线 · 2 位”表达状态时，行内只保留头像点，不再叠加状态文字。
- **群聊头**没有个人头像点，才用 meta 的一个点 + “3 人在线”。
- **网络状态**单独一层：统一写“局域网已连接 · 4 台设备”，不重复“在线”。
- **未读、置顶、静音、传输**各自只占一个槽位，不叠加两个角标或两个状态点。
- 若必须同时表达“在线 + 勿扰”，用头像点 + 静音图标两个不同语义，不重复在线。

## 3. CSS 契约（实现时照此落地）

```css
/* 所有 flex/grid 中间列 */
.min0{min-width:0}

/* 单行省略 */
.one-line{
  white-space:nowrap;
  overflow:hidden;
  text-overflow:ellipsis;
}

/* 两行截断 */
.two-line{
  display:-webkit-box;
  -webkit-line-clamp:2;
  -webkit-box-orient:vertical;
  overflow:hidden;
}

/* 气泡与长链接 */
.bubble{
  overflow-wrap:anywhere;
  word-break:break-word;
}

/* 技术串 */
.mono{
  font-family:"JetBrains Mono","SFMono-Regular",Consolas,monospace;
  word-break:break-all;
}
```

注意事项：

- `text-overflow:ellipsis` 必须配合 `overflow:hidden` 和 `white-space:nowrap`；父级还要 `min-width:0`，否则 flex 子项不会收缩。
- 不要给正文加 `word-break:break-all`，会把正常英文单词切碎；只在技术串上用。
- `-webkit-line-clamp` 需要 `display:-webkit-box`，并且元素不能是 `display:flex`。
- 单行省略项在桌面要有 `title` 或可访问名称；移动端通过资料页/长按复制兜底。

## 4. 复杂信息页（设置、任务、搜索、群资料）

参考 Apple 设置与文件 App 的分组方式：

- **分组卡片**：16px 圆角、白色表面、发丝线分隔；组间 12–16px，组内行 48px。
- **一行只做一个决定**：左侧标签 + 说明，右侧值/开关固定；说明最多两行。
- **层级靠字重和留白**：分组标题 11px/600，正文 13–14px，辅助 11px；不靠 9px 小字。
- **长路径不换行撑高**：路径/错误原因两行截断，完整内容通过详情或复制查看。
- **数字用 tabular-nums**：时间、大小、百分比、未读对齐不跳动。
- **键盘与缩放到 200%**：文本放大后允许换行，不允许横向滚动；触控目标保持 ≥44px。

## 6. 检查清单

- [ ] 任意页面横向滚动条都不应出现（`document.scrollingElement.scrollWidth <= clientWidth`）。
- [ ] 长名称不把时间/未读/按钮挤出容器。
- [ ] 长 URL 在气泡内断行，气泡不超出最大宽度。
- [ ] 文件名、路径、错误原因按约定行数截断。
- [ ] 技术串完整显示或可复制，不被裁切一半。
- [ ] Toast / 对话框标题最多两行，按钮文字不换行。
- [ ] 输入长草稿不丢字，发送键位置不动。
- [ ] 字号放大到 16px、浏览器缩放 200% 时布局仍可用。
- [ ] 截断项有 `title` / 资料页 / 复制等查看全文的兜底。

## 7. 当前原型的限制

- 原型里的输入框是单行 `<input>`，用于演示发送流程；正式实现应为可增长到 5 行的 `<textarea>`，超过后内部滚动。
- 截断项的 `title` 提示、长按复制和拖拽选字属于实现细节，静态画板只表达布局与收束方式。
- 桌面 `02 Desktop coverage` 的密集画板不是每个都放了极端字符串；本规范与 `05 Edge cases` 是验收依据。
