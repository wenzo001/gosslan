# 评审清单

> 打开设计画布后，按页面逐项检查。每一项都对应一个可看的画板；有争议的地方直接在设计稿上批注即可。

## v2.2 + 品牌先看这些

- [ ] 小院是否“抽象又能看懂”：蓝院墙 + 奶油拱门 + 绿苗；16px 是否还能认。
- [ ] 应用图标是否比之前的嵌套方块更干净：满版蓝底 + 拱门 + 小苗，没有第二个圆角方块。
- [ ] 吉祥物表情放在门洞里是否自然；日常/成功/处理中/离线/出错五态是否一致。
- [ ] 应用图标在 macOS / iOS / Android / Windows 上是否同一图案；1024、64、32、16px 是否都清楚。
- [ ] Rounded 2.0 图标是否比旧图标更圆润、更有分量；收藏改用书签是否接受。
- [ ] 导航/顶栏/发送/附件等高频图标替换后，是否仍然一眼可懂。
- [ ] 桌面、移动端、设置/任务/日志等窗口的图标是否同一套形状，只改尺寸。
- [ ] 同一个在线状态是否只出现一次：头像点或文字状态，不叠加第二个点。
- [ ] 未读、置顶、静音、网络、传输状态是否各自只占一个槽位。

## v2.2 先看这些

- [ ] 62px（桌面）/ 64px（移动）行高是否够紧凑，同时不觉得拥挤。
- [ ] 圆润度是否合适：控件 10px、卡片 16px、气泡 20px、抽屉 22px；嵌套是否同心。
- [ ] 设置/任务/搜索的分组卡片与 48px 行是否比 v2.1 更清楚。
- [ ] 长文本：会话名、预览、URL、文件名、IPv6、安全码、Toast、长草稿是否都不撑破布局。
- [ ] 辅助字号抬到 11px 后，信息量是否仍够。
- [ ] 看 `05 Edge cases` 两块画板，逐条确认收束方式。

## v2.1「Pulse」先看这些

- [ ] 整体是否像微信 / QQ / 飞书那样「熟悉、清晰、年轻团队」，而不是社交 App 或后台系统。
- [ ] 主蓝 + 未读红 + 在线绿 + 少量置顶金是否足够；是否还要更活泼，或再收一点。
- [ ] 自己气泡的纯蓝色是否喜欢；气泡预设是否够用（跟随主题/蓝/红/绿/金/深灰，另可自定义）。
- [ ] 添加好友整页列表是否比弹窗更自然；遮罩“没盖全”的问题是否消失。
- [ ] 个性化（主题色/气泡颜色/字号/实时预览）是否够用；是否要加自定义取色。
- [ ] 图片预览窗的工具栏、缩略图、保存/定位是否完整；是否要加“文件已清理”态。
- [ ] 移动端顶栏「+」是否够用（本版默认不放 FAB）；4 tab 是否熟悉。
- [ ] 好友申请冷却态是否合理；被拒绝是否应该静默。
- [ ] Flow closures 板：搜索返回、多选批量、强提醒回执、群文件/任务 tab、链接导入预览、传输完成后的“打开”是否把闭环补齐。
- [ ] 群任务卡在气泡流里是否太重；逐人已读是否信息过载。
- [ ] v2.1 是否整体替换 v1，还是保留两套按页面选择。
