# v2.1 — 参考微信 / QQ / 飞书的收束

## 反馈

- 这是私有网络里的团队聊天工具，不是社交游乐场。
- 参考微信、QQ、飞书这些更年轻、但更主流的软件。
- 文案要大众认知，不要自造概念（“同频”“打招呼”“一点电”）。
- 功能清晰、风格统一，可以保留定制化，但不要花里胡哨。

## 决策

保留 v2 的结构与新增能力，换掉“设计感过强”的部分：

| 维度 | v2.0 Pulse | v2.1（本版） |
| --- | --- | --- |
| 主色 | 紫罗兰 + 四强调色 | **飞书/QQ 蓝 `#2F6BFF` + 微信绿 `#07C160` + 红 `#FA5151` + 少量金 `#FFB400`** |
| 底色 | 淡紫 | **中性灰白 `#F2F3F5` / `#F7F8FA` / `#FFFFFF`** |
| 字体 | Space Grotesk 标题 | **系统字体（PingFang SC / Microsoft YaHei / Segoe UI）** |
| 自己气泡 | 紫渐变 | **纯蓝 `#2F6BFF`** |
| 未读 | 珊瑚胶囊 | **微信红 `#FA5151`** |
| 在线/成功 | 薄荷色 | **微信绿 `#07C160`** |
| 移动端 | 4 tab + 浮动 FAB | **4 tab，仅保留顶栏 “+”（微信/QQ/飞书习惯）** |
| 空状态 | 光环 + 大标语 | **线性图标 + “选择一个会话” + 添加好友/创建群聊** |
| 发现页 | 雷达 + “同频的人” | **“添加好友”列表：附近设备 / 邀请码，按钮“添加”“等待确认”“发消息”** |
| 文案 | 品牌化 | **大众认知：添加好友、发现设备、等待确认、发消息、复制邀请** |

## 保留

- 整页“添加好友”，不再用半透明遮罩弹窗。
- “个性化”：主题色 / 气泡颜色 / 字号 / 动效 + 实时预览。
- 图片预览窗、启动错误窗、Flow closures 六个闭环。
- iMessage 式单聊布局、紧凑气泡、群聊头像 + 名字。
- 深色/浅色两套同层级。

## 不保留

- 光环、雷达、渐变气泡、FAB、超大营销标题、“同频”概念。
- 任意双色渐变作为默认；自定义仍作为“需产品确认”的定制项保留。
- “不用加好友也能先聊”这种不存在的行为。
