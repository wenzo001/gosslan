# Gosslan Pulse — 设计系统 v2.2

> 参考微信、QQ、飞书的熟悉感，为小团队做一套紧凑、圆润、清晰、可定制的局域网聊天。
> 不是社交游乐场；是团队每天打开就能用的工具。

---

## 1. 方向

Pulse 保留 v1 的信息架构与功能闭环，但不再用「设计感」压过「好用」：

- **熟悉**：左 rail + 会话列表 + 聊天；移动端 4 tab + 顶栏「+」；添加好友是列表页，不是花哨弹窗。
- **清晰**：蓝=动作，红=未读/危险，绿=在线/成功，金=置顶；一屏最多三种强调色。
- **统一**：系统字体、8px 节奏、6–22px 同心圆角、发丝线分层，页面之间不换语言。
- **可定制**：主题色、气泡颜色、字号、动效可调，有实时预览；但不把定制做成装饰。
- **年轻但不幼稚**：干净的灰白底、清晰的蓝、少量彩色头像与轻反馈；不用吉祥物、彩虹渐变、满屏 emoji。
- **紧凑但清楚**：桌面行高 62px、移动 64px，设置行 48px；信息越密，越依赖固定槽位、单行省略和分组卡片，而不是缩小字号。
- **圆润的苹果式几何**：控件 10px、卡片 16px、气泡 20px、面板/底部抽屉 22px；嵌套圆角按「外圆角 − 间距」同心递减，最小 8px。参考 Apple HIG 的清晰层级与连续圆角，但不照搬玻璃材质。

参考坐标：微信的克制列表与输入区、QQ 的年轻配色与可定制、飞书的团队协作信息密度。

## 3. 字体

系统字体优先，保证中文渲染与跨平台熟悉感：

```css
-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif
```

| 样式 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display-lg` | 28/34 | 600 | 空状态/页面大标题 |
| `display` | 24/30 | 600 | 区块标题 |
| `title-lg` | 20/26 | 600 | 设置分区 |
| `title` | 17/24 | 600 | 会话/弹窗标题 |
| `headline` | 15/20 | 600 | 列表分组、按钮 |
| `body` | 14/20 | 400 | 消息、设置行 |
| `body-strong` | 14/20 | 500 | 会话名、未读 |
| `body-sm` | 13/18 | 400 | 摘要、输入 |
| `caption` | 12/16 | 400 | 时间、辅助 |
| `micro` | 11/14 | 500 | 发送者名、徽标 |

- 中文正文行高不低于 1.4×；消息 14/20（桌面）、15/21（移动）。
- **最小 11px**（桌面密集卡片也不低于 10.5px）；字重不超过 600；数字用 tabular-nums。
- 不引入展示型西文字体；团队工具的熟悉感优先。

## 4. 形状与层级

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-xs` | 6px | 行内代码、小徽标、复选框 |
| `radius-sm` | 8px | 小控件、菜单行、内嵌字段 |
| `radius-md` | 10px | 按钮、输入、搜索槽 |
| `radius-lg` | 14px | 缩略图、群头像、内层卡片 |
| `radius-xl` | 16px | 分组卡片、设置组、对话框 |
| `radius-bubble` | 20px | 消息气泡；连接角 6px |
| `radius-2xl` | 22px | 底部抽屉、输入区外壳、大媒体卡 |
| `radius-full` | 999px | 头像、状态点、胶囊 |

- **同心圆角**：嵌套圆角 = 外层圆角 − 间距，最小 8px。例：16px 卡片 + 8px 内边距 → 内层 8px；22px 抽屉 + 8px 内边距 → 内层 14px。
- 阴影轻、中性：`0 4px 14px rgba(16,17,20,.10)`；对话框 `0 28px 72px rgba(9,10,12,.32)`；不使用带颜色的阴影。
- 内容区不做玻璃；只有标题栏/底栏可以 92% 不透明 + 轻微模糊。
- 头像：2px 白环；在线点绿色。群头像 13px 圆角方形。
- 列表行 62px（桌面）/ 64px（移动），设置行 48px，聊天头 52px；控件高度 30/36/44px。

### 4.1 密度与对齐

| 区域 | 桌面 | 移动 |
| --- | --- | --- |
| 页面/聊天头 | 52px | 52px |
| 会话/联系人行 | 62px，头像 42px | 64px，头像 42px |
| 设置行 | 48px | 48px |
| 底部 tab | — | 56px + safe area |
| 输入区 | 56px 起，随内容增长 | 52px 起，随键盘上移 |
| 列表宽 | 320px（280–400） | 全宽 |

### 4.2 复杂信息页的清晰度

参考 Apple 设置与文件 App 的分组方式，而不是把信息压成一张大表：

- **分组卡片**：16px 圆角、白色表面、发丝线分隔；组间 12–16px，组内行 48px。
- **固定槽位**：时间、未读数、右侧状态/按钮固定宽；中间文本 `min-width:0` + 单行省略。
- **最多两行**：搜索摘要、任务错误原因、文件路径最多 2 行；超出省略，不撑高整行。
- **技术串**：IPv6、安全码、文件路径用等宽字体，允许任意断行；绝不横向溢出。
- **不缺字号**：靠分组、留白和字重建立层级，不靠 9px 小字塞信息。

## 5. 图标与品牌

### 5.1 Rounded 2.0

- 24×24 网格，视觉区 20×20；**2px** 圆头描边，16px 时降到 1.8px；尺寸 16/20/21/23/24。
- 自定义几何：会话=圆角气泡，通讯录=两个人，收藏=书签，设置=两条滑杆，发送=圆头箭头，更多=三个 1.4px 实心点。
- 一个主形状 + 最多一条辅助线；不混用线性与填充图标，不加阴影/渐变/emoji。
- 桌面、移动端和所有辅助窗口共用同一套 path；只按端调整 21/23px 与热区，不单独设计两套图标。
- 图标按钮移动端 ≥44px 热区，桌面 30–36px；图标本身不放大热区。
- 完整图标表见画布 `06 Brand` 的 `IconSet`，组件预览见 `components/IconSet/`。

### 5.2 小院（吉祥物）

- 一座小院子：蓝色院墙（squircle）+ 奶油拱门 `#fff8ea` + 绿苗 `#07c160`；抽象到 16px 仍能认。
- **标记（无表情）**：导航、角标、App 图标、16–32px。
- **吉祥物（有表情）**：眼睛和微笑放在奶油门洞里，用于空态、欢迎页、成功/离线/出错，72–120px。
- 16px 时去掉表情，小苗收成绿点；状态只改身体/表情/小徽标，不改变轮廓；出错时身体仍为蓝色，红点只做提示。
- 应用图标：1024 满版蓝底 + 奶油拱门 + 绿苗；macOS 22.37% 连续圆角、iOS/Windows 满版、Android 66% 安全区、Tinted 单色。桌面/移动/各窗口共用同一图案。
- 源文件在 `designs/gosslan-redesign/brand/`：`xiaoyuan-mark.svg`、`xiaoyuan-mascot.svg`、`app-icon-light.svg`、`app-icon-dark.svg`、`app-icon-macos.svg`、`app-icon-ios.svg`、`app-icon-android.svg`、`app-icon-tinted.svg` 与 `png/` 尺寸梯。

## 6. 核心组件

### 6.1 会话行

- 62px（桌面）/ 64px（移动），14px 内边距，42px 头像；名称 14.5–15/19–20 500（未读 600），摘要 12.5/17。
- 未读：红色胶囊（`spark`），白字，18px；免打扰用小铃铛，不叠加。
- 选中：`accent-soft` 整行；不加左色条。
- 置顶：顶部 10px「置顶」标签 + 金色小点。
- 群头像 13px 圆角方形；人物头像圆形。

### 6.2 消息气泡

- 自己：`accent` 纯蓝、白字、右下 6px；对方：`bubble-in` 灰、左下 6px。
- 单行 38px；组内 2px、换组 12px；最大 68%（桌面）/ 78%（移动）或 560px；长链接与长单词 `overflow-wrap:anywhere`。
- 单聊无头像列；群聊 24px 头像 + 11px 名字，只在组首。
- 回执只在自己最后一条：clock / check / double-check / 失败+重试。
- 引用在气泡内左侧 2px 细线；回应是 26px 胶囊，弹入 180ms。
- 图片 14px 圆角；文件卡 14px 圆角、1px 边界；长文件名单行省略。

### 6.3 输入区

- **整行输入区**，不是浮动大卡片：上边 1px `divider`，左右 16px、上下 10px。
- 内部输入框 8px 圆角、`surface-field` 底；左侧附件/图片/表情，右侧蓝色发送圆钮。
- 空内容发送钮 `surface-field` + `text-tertiary`；聚焦时输入框 2px `focus-ring`。
- 移动端 44px 触控；输入区随键盘上移。

### 6.4 头部

- 52px；头像 32px（群 34px 圆角方）；名称 15/20 600；第二行 11px 在线/离线 + 链路。
- 右侧最多 3 个 30px 图标；更多放菜单。
- 在线绿点 + 文字；离线灰点 + 文字；不只用颜色。

### 6.5 添加好友（整页）

- 从「+」进入，整页列表，不再用 440px 弹窗 + 半透明遮罩。
- 标题「添加好友」；副标题「同一局域网内的设备会自动出现」。
- 两个入口：附近设备 / 邀请码。
- 设备行：头像、昵称、设备/链路、状态，按钮为「添加」「等待确认」「发消息」。
- 状态：加载、无设备、蓝牙未开、搜索失败；每种都有下一步。
- 不承诺「不用加好友也能聊」；必须先发送申请。

### 6.6 个性化（主题 + 气泡）

- 一页完成：主题色、气泡颜色、字号、动效、实时预览。
- 主题色：6 个预设 + 自定义取色；默认主蓝；只影响本机（待产品确认是否同步）。
- 气泡颜色：默认纯蓝 + 5 套预设；自定义双色作为「需产品确认」的扩展。
- 字号：12–16px 五档，行高联动。
- 气泡颜色会同步给聊天对象；主题色只影响本机。同步说明必须写在页面底部。
- 设置即时保存，底部「恢复默认」。

### 6.7 菜单、弹窗、Toast

- 菜单：白底、8px 圆角、轻阴影、32px 行；危险项红字。
- 对话框：最大 420px、16px 圆角；标题 17/24，正文 13/18；主按钮在右。
- Toast：桌面右下、移动底部居中；图标 + 文字；不遮标题栏。
- 破坏性确认写清对象与后果，按钮用动词。

### 6.8 状态

**一个状态只出现一次。**

- 头像有在线/离线点时，旁边不再出现第二个绿点或“在线/离线”文字；只保留设备、网络等上下文。
- 联系人按“在线 / 离线”分组时，组标题已经表达状态；行内只保留头像点，不再叠加文字状态。
- 群聊头没有个人头像点，才用 meta 的一个点 + “3 人在线”。
- 网络状态是另一层信息：统一写成“局域网已连接 · 4 台设备”，不重复“在线”。
- 未读、置顶、静音、传输状态各自只占一个槽位；不叠加两个角标。

- 空/错误/加载/离线共用：40px 线性图标 + 20/26 标题 + 13/18 说明 + 一个主行动。
- 加载用 3–5 行骨架，保持最终几何；不做整页 spinner。
- 错误就地显示，永远带「重试」；不丢输入。
- 离线：32px 细横幅 + 头部状态；输入不锁，消息排队可见。
- 传输：图标 + 状态词 + 进度 + 速度/原因；完成后保留「打开」。

## 7. 动效

- 标准 `cubic-bezier(.2,0,0,1)`；时长 150 / 200 / 240ms。
- 只动 `opacity` 与 `transform`；reduce 档只保留 120ms 淡入淡出。
- 出现只播一次；状态切换（选中、已读、发送成功）不重播缩放入场。
- 不做常驻背景动画；不做弹跳/光晕/雷达扫描。

## 8. 可访问性

- 正文 4.5:1，图形/焦点 3:1；红/绿当文字时用更深一档。
- 键盘：Tab、Esc、⌘K、Enter、方向键。
- 图标按钮有 `aria-label`；输入有可见 label；装饰图标 `aria-hidden`。
- 触控目标 ≥ 44px；200% 文本缩放不重叠。

## 10. 使用方式

- 所有页面从 `tokens.json` 取值；画板内以十六进制落地，便于设计工具读取。
- 新增组件先回答：它在哪个表面？hover/pressed/focus/disabled/loading/error 是什么？占多少高度？
- 默认拒绝：大面积渐变、彩色卡片堆叠、emoji 当图标、无意义动效、超大字营销标题。
- 允许的「年轻」：干净底色、清晰蓝、彩色头像、克制的轻反馈、可定制主题。
