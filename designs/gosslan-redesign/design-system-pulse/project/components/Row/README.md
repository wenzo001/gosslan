# Row

List rows are the densest surface. Pulse makes them scannable but not sterile.

- Height 68px, 16px horizontal inset, 12px gap; avatar 44px.
- Name: 15/20, 500 (600 only when unread). Preview: 13/18, `text-secondary`, one line.
- Time: 11px `text-tertiary`, tabular; top aligned.
- Unread: a **red (`spark`) capsule**, white label, 18px minimum. Muted chats show a small bell instead. Never stack two badges.
- Selected row: `accent-soft` across the full row; no left colour bar.
- Pinned rows sit at the top with a 10px "置顶" label and a gold dot, not a separate section.
- People avatars are circles; group avatars are 24px squircles. Both carry a 2px white ring and `shadow-sm`.
- Presence dot is 10px green with a 2px surface ring.
- Contact rows add a 30px message action on the right; no chevron-only affordance.
