# Settings

Settings are a calm list, but personalization gets the stage.

- Desktop: 200px sidebar, 9 sections, one section per page. Mobile: 4 groups, 9 rows, each row drills into a section.
- **Personalize** merges theme color, bubble palette, font size, motion and transparency into one page with a live chat preview.
- Theme color: 6 presets + custom color picker; applies immediately. Bubble palette: 6 presets + custom two-color gradient; the footnote explains that bubble colors sync to peers while theme color is local (pending product confirmation).
- Rows are 52–54px, label 14/20, optional 12px description, control on the right.
- Controls: segmented for 2–3 choices, switch for booleans, select for longer lists, slider with five labelled steps for chat font size.
- Destructive actions live in their own group with `danger-ink`; never a red filled row.
- Settings save immediately; the footer says so instead of showing a Save button.
- Every summary in the mobile index answers "what is it set to now" (`跟随系统`, `14px`, `1.2 GB / 5 GB`).
