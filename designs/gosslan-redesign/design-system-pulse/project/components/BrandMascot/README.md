# BrandMascot — 小院

“小院”是 Gosslan 的品牌标记与吉祥物：一座蓝色小院子，奶油拱门，一株绿苗。

- **标记（无表情）**：用于导航、角标、App 图标、16–32px 场景。
- **吉祥物（有表情）**：眼睛和微笑放在奶油门洞里，用于空态、欢迎页、成功/离线/出错状态，72–120px。
- 三种颜色：院墙 `accent`、门洞/表情 `#fff8ea`、小苗 `#07c160`。不使用渐变、阴影叠阴影或写实屋顶。
- 16px 时去掉表情，小苗收成一个绿点；门洞加宽，避免糊成一团。
- 状态只改变身体/表情/小徽标，不改变基本轮廓；出错时身体仍为蓝色，红点只做提示。
- App 图标浅色用奶油底 + 蓝院墙；深色用深底 + 亮蓝院墙。按 Apple 图标网格保留方形画布，圆角由系统或导出时处理。
