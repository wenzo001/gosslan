# Navigation

Two navigation surfaces, one compact language.

- Desktop rail 64px: avatar at top, four destinations (Chats, Contacts, Favorites, Links), theme and more at the bottom. Icons 22px at 1.75px; active state is a 38px rounded-10 pill in `accent-soft`, icon in `accent-ink`.
- Unread counts use one 16px red (`spark`) capsule on the icon's top-right; never a dot plus a count.
- Mobile tab bar is 56px + safe area: Chats, Contacts, Favorites, Me. Active state is a 46×26 `accent-soft` pill behind a 21px icon, 11px label below.
- Mobile list pages put a **44px top-right「+」** in the header for a new chat — no floating FAB. It is an action, not a fifth tab; detail pages show back + contextual actions instead.
- Desktop title bar is 40px: window controls at the platform side, a quiet centred app name, LAN status + search at the right. Nothing floats above it.
- Detail pages hide the tab bar; back is a 44px target at the top-left.
